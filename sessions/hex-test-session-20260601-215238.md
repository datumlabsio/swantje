#### Cell 4 — Top 10 Customers Revenue SQL (`019e8417-803d-731d-846f-7998ea36b46b`)
```sql
WITH monthly_revenue AS (
    SELECT
        c.C_CUSTKEY                                  AS customer_id,
        c.C_NAME                                     AS customer_name,
        c.C_MKTSEGMENT                               AS segment,
        DATE_TRUNC('month', o.O_ORDERDATE)           AS order_month,
        SUM(l.L_EXTENDEDPRICE * (1 - l.L_DISCOUNT)) AS revenue
    FROM CUSTOMER   c
    JOIN ORDERS     o ON o.O_CUSTKEY = c.C_CUSTKEY
    JOIN LINEITEM   l ON l.L_ORDERKEY = o.O_ORDERKEY
    GROUP BY 1, 2, 3, 4
),
latest_month AS (
    SELECT MAX(order_month) AS m FROM monthly_revenue
)
SELECT
    mr.customer_name,
    mr.segment,
    mr.order_month,
    ROUND(mr.revenue, 2)                                              AS total_revenue,
    RANK() OVER (ORDER BY mr.revenue DESC)                            AS revenue_rank
FROM monthly_revenue mr
JOIN latest_month lm ON mr.order_month = lm.m
ORDER BY revenue_rank
LIMIT 10
```
Output dataframe: `top_customers`  
Connection: `019a30e0-579e-7004-9f86-acab029caec8` ([Demo] Hex Public Data)

## Observations / Notes

- `hex cell run-status` does not exist — the CLI has no way to poll run status or read back result data. Cells run fire-and-forget; results are only visible in the browser.
- The demo Snowflake connection uses TPC-H sample data (historical, dates up to ~1998). The revenue query dynamically finds the most recent month in the data via `MAX(order_month)` rather than filtering on the current calendar month — otherwise the result set would be empty.
- `hex project create` does not accept `--title <value>` flag; the title is a positional argument.
- Column names in `top_customers` dataframe will be uppercase (Snowflake default), so Python references use `TOTAL_REVENUE`, `CUSTOMER_NAME`, `ORDER_MONTH`, `SEGMENT`.
